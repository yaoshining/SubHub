# v0.2.1 发布说明

发布日期：2026-06-23

## 概览

v0.2.1 为已发布字幕搜索 API 增加非破坏性的结构化检索字段。

## 主要内容

- 增加 `imdb_id`，用于 IMDb 标识检索。
- 增加 `tmdb_id`，用于 TMDb 标识检索。
- 增加 `type`，支持 `movie` 与 `episode` 类型约束。
- 补齐 `type` 与季、集字段的冲突校验，保持既有字段命名与 API 兼容性。

## 边界

未引入多 Provider 能力模型、Provider 路由或 fallback 编排，也不包含字幕资产管理。
