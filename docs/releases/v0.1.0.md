# v0.1.0 发布说明

发布日期：2026-05-31

## 概览

v0.1.0 是 SubHub 的首个可用 MVP 闭环，交付管理控制台与统一字幕查询、下载出口。

## 主要内容

- 管理员初始化、登录认证与会话安全边界。
- Dashboard 系统摘要与就绪状态展示。
- OpenSubtitles Provider、凭据池及其管理界面。
- Caller Key / API Key 管理与受控调用能力。
- 用户邀请、暂停恢复与基础会话处置。
- Settings 只读状态页面，以及 OpenAPI、Orval、Scalar API 契约链路基础。

## 边界

该版本仍使用 SQLite 基线；Postgres、Neon 与 Vercel 的生产化部署能力由 v0.2.0 承接。
