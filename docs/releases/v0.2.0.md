# v0.2.0 发布说明

发布日期：2026-06-15

## 概览

v0.2.0 在不扩大 v0.1.0 产品功能范围的前提下，建立数据库与部署的生产化基线。

## 主要内容

- 存储层迁移至 Neon Postgres，并建立正式 migration 基线。
- 收敛 Vercel 运行时环境与 `DATABASE_URL` 映射规则。
- 明确 Production、Preview、Development 的数据库目标与分支白名单护栏。
- 建立生产环境 readiness gate、部署 smoke 检查及 GitHub Actions 最小迁移/部署门禁。
- 收敛 Postgres bootstrap、首位管理员初始化和非生产环境 seed 规则。

## 边界

此版本聚焦运行与部署基础设施，不包含字幕搜索字段扩展、多 Provider 搜索，或 Provider 管理台配置能力。
