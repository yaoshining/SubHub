# v0.2.2 发布说明

发布日期：2026-06-30

## 概览

v0.2.2 建立多 Provider 聚合字幕搜索的最小模型，并完成迅雷字幕 Provider 的基础接入。

## 主要内容

- 引入 Provider adapter 抽象与 registry，收敛 OpenSubtitles 接入边界。
- 接入迅雷字幕 Provider，建立名称检索型 Provider 的落地样本。
- 支持按 Provider 能力选择性消费请求字段，并统一标准化搜索结果和来源标识。
- 增加多 Provider 聚合、失败隔离、响应状态及最小 fallback 策略。
- 统一下载路由支持迅雷链接解析，同步 OpenAPI 契约和生成客户端。

## 边界

迅雷 Provider 在本版本可由后端调用，但不提供管理台配置、启停、状态展示或数据库元数据持久化；这些能力由 v0.2.3 承接。
