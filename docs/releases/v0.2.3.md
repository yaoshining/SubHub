# v0.2.3 发布说明

发布日期：2026-07-19

## 概览

v0.2.3 补齐已接入字幕 Provider 的运营管理面，并交付仅供管理员使用的 Subtitle API Validator 工具。

## Provider 管理能力

- Provider 管理台统一展示 OpenSubtitles 与迅雷，支持列表、详情、基础策略配置、启用/禁用及健康状态查看。
- Provider 元数据持久化至数据库；迅雷作为预置 Provider 参与调度，同时保留 v0.2.2 的聚合搜索行为。
- 新增两步式 OpenSubtitles 创建流程。迅雷为预置单实例，界面明确限制且禁止重复创建。
- 详情页和列表按 Provider 类型展示结构性能力差异：OpenSubtitles 使用凭据池，迅雷展示受限且无需 API Key 的能力模块。

## Subtitle API Validator

- 提供仅限管理员使用的 Provider 验证工作台：查看能力与配置、执行搜索验证、查看结果与诊断摘要，并执行下载验证。
- Validator 与正式 `subtitles` caller-key 链路解耦，避免排障工具与对外业务鉴权语义耦合。
- 诊断支持错误分类、下一步操作提示、Provider-aware 参数分组、下载模式说明和脱敏错误摘要。
- 同步 OpenAPI、Orval 生成 client/types 及前端 facade，维持契约一致性。

## 可靠性与体验

- Dashboard 摘要卡片内联展示就绪状态。
- CI 环境映射与 URL 护栏测试改为只执行目标测试；Provider 启停 UI 测试降低慢速 CI 的时序敏感性。
- Provider 管理 page spec、README 和 API 文档与当前实现完成校准。
